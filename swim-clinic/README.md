画像はすべて `images/` からの相対パスで読み込んでいます。フォルダごと配置すればそのまま表示されます。

## 2. やってほしいこと

1. `swim-clinic-lp/` を既存サイトの新しいページとして配置する
   （例：`/swim-clinic/` などのURLで公開）
2. 既存サイトのナビゲーション／トップページなど、指定の場所からこのページへのリンクを追加する
3. 既存サイトの共通ヘッダー・フッターを付ける場合は、**このLPのデザインと干渉しないよう**に注意する
   - このLPのCSSは `body`, `h1`〜`h3`, `p`, `a`, `section` などに直接スタイルを当てています。
     既存サイトのCSSと混ざると崩れるので、必要なら LP 全体を1つのラッパー（例：`.swim-clinic-lp`）で囲み、CSSのスコープを限定してください。
   - 逆に、既存サイトの共通CSSがLP側に影響しないかも確認してください。
4. 既存サイトのビルド環境（WordPress / 静的サイトジェネレーター / React 等）に合わせて組み込む
   - 単体の静的HTMLとして置くのが一番安全です。

## 5. デザイン上のルール（崩さないでほしい点）

- **改行**：見出しや強調文は `<span class="nb">` で文節ごとに区切り、言葉の途中で改行しないようにしています。テキストを差し替えるときもこの仕組みを残してください。
- **TOPのタイトル画像3点**は同じ横幅（`--hw-w`）に揃えています。
- **TOPの白い部分と波**は、境目が出ないよう同じ `<section class="hw-top">` の中に入れています。分離しないでください。
- **スマホ表示**で、「20代と同じだけ泳いでも…」の文は読点ごとに改行（`.pull-fit`）、「公式LINEご登録者さま」ラベルは中央寄せです。
- 主な枠（経歴・選手カード・著書・Part・対象リスト・日付ボックス）は「角丸なしの金ライン4px＋四隅に8pxの四角」で統一しています。
- 文字の太さ：本文500／小見出し・強調700／大見出し・名前900。
